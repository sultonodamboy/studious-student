# Odamboy Sultanov — Portfolio sayti

## VS Code'da ochish
1. VS Code'ni oching: File → Open Folder → `portfolio-sayt` papkasini tanlang.
2. Extensions bo'limidan **Live Server** o'rnating.
3. `index.html` ustida o'ng tugma → **Open with Live Server**.

## Fayllar
- `index.html` — sahifa tuzilishi va matnlar
- `css/style.css` — dizayn, ranglar, animatsiyalar
- `js/main.js` — effektlar (yozilayotgan matn, 3D kartalar, rejim tugmasi)

## Nimani o'zgartirish kerak
- Ism, loyihalar, ko'nikmalar, statistika: `index.html`
- Ranglar: `css/style.css` boshidagi `:root` ichida
- Kasblar ro'yxati: `js/main.js` ichidagi `roles`

## Internetga joylash
Papkani Netlify, Vercel yoki GitHub Pages'ga yuklang. Qo'shimcha sozlash kerak emas.
